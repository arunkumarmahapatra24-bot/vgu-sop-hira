# VGU-SOP, SMP, WI & HIRA Management System — Google Sites hosting

This folder is ready for GitHub Pages. `index.html` is the complete app (single file).

1. github.com → New repository → name `vgu-sop-hira` → Public → Create.
2. Add file → Upload files → drag `index.html` and `.nojekyll` → Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch `main`, folder `/ (root)` → Save.
4. After 1–2 minutes the app is live at `https://<your-github-username>.github.io/vgu-sop-hira/`.
5. Google Sites → open your site → Insert → Embed → By URL → paste the link → "Whole page" → Insert.
   Drag the embed box to full page width and about 900 px tall → Publish.

To update the app later: upload the new `index.html` to the same repository (replace) — the Google Site updates automatically.
